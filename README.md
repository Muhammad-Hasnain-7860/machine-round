# Interview Tracker

A web application that helps students organize interview questions and track their preparation progress category-wise.

##  Live Demo

[View Interview Tracker](https://machine-round-sage.vercel.app/)

## GitHub Repository

[View Source Code](https://github.com/Muhammad-Hasnain-7860/machine-round)

##  Features

- Add new interview questions.
- Update and delete existing questions.
- Track question completion status.
- View overall preparation progress.
- Track progress category-wise.
- Pagination to navigate through questions.
- Search questions by keyword.
- Filter questions by category.
- Separate Pending Questions page for incomplete questions.
- Search and filter pending questions.

##  Tech Stack

- React
- Tailwind CSS
- React Hook Form
- React Hot Toast
- React Router
- Redux

##  Installation and Setup

1. Clone the repository:

   git clone https://github.com/Muhammad-Hasnain-7860/machine-round.git
   

2. Navigate to the project folder:

   
   cd machine-round
   

3. Install dependencies:

   npm install
   

4. Start the development server:

   npm run dev
  

5. Open the local URL displayed in your terminal.

##  Assumptions

- Students manually update a question's completion status.
- Questions marked as incomplete appear on the Pending Questions page.
- Questions are organized into categories to track preparation progress.

##  Purpose

The goal of this project is to help students manage interview preparation in an organized way and monitor their progress.
